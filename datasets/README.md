# Datasets

Diretório de conjuntos de dados **exclusivamente sintéticos**. Na inicialização, o backend cria `fisioterapia/pacientes_fisioterapia.csv` e `fisioterapia/pacientes_fisioterapia.xlsx`, com 1000 pacientes e seed 42 se o padrão ainda não existir.

Nenhum dado clínico real deve ser armazenado aqui.
